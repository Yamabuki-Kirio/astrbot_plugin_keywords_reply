# 关键词回复（个人维护版）

> 本仓库由 [Yamabuki-Kirio](https://github.com/Yamabuki-Kirio) 基于
> [Foolllll-J/astrbot_plugin_keywords_reply](https://github.com/Foolllll-J/astrbot_plugin_keywords_reply)
> 二次开发，遵循 AGPL-3.0 许可证。这是根据个人实际使用需求维护的公开版本，
> 不代表上游官方版本，也不发布到 AstrBot 插件市场。

## 与上游版本的区别

本维护版保留上游的关键词、检测词、富媒体回复和 WebUI 管理能力，并新增：

- `/添加 <触发词>` 多轮会话式录入。
- 连续收集多条文字、图片、语音或视频。
- `/结束添加` 后按原始录入顺序逐条回复，而不是随机选择一条。
- `/取消添加` 主动放弃当前录入。
- 录入状态 5 分钟无操作自动失效。
- 按平台、群聊和操作者 ID 隔离录入状态。
- 录入者之外的群成员消息不会被收集。
- 录入期间拦截录入者的素材消息，避免同时触发旧规则或进入 LLM。
- WebUI 保存规则时保留 `sequential` 顺序回复属性。
- 插件版本更新为 `v1.5.0`。

## 会话式添加

使用示例：

```text
用户：/添加 123
Bot：请发送要回复的内容，可连续发送文字、图片、语音或视频。
     完成后发送 /结束添加；放弃请发送 /取消添加。

用户：[图片]
用户：文字示例
用户：/结束添加
Bot：添加成功：检测词“123”，共 2 条回复。
```

之后有人在当前群发送包含 `123` 的消息，Bot 会先发送图片，再发送文字。

注意：

- 会话式添加创建的是普通“检测词”，采用包含匹配。
- 在群聊创建时默认只在当前群启用。
- 在私聊创建时默认全局禁用，需要管理员后续设置启用范围。
- 已存在相同检测词时会拒绝重复创建。
- 只有 AstrBot 管理员或插件白名单用户可以录入。

## 原有规则管理

### 指令触发型关键词

关键词需要通过 `/关键词` 形式主动触发。

```text
/添加关键词 <关键词> <回复内容>
/编辑关键词 <序号或内容> <新关键词>
/删除关键词 <序号或内容>
/查看关键词列表
/查看关键词 <序号或内容>
```

### 自动监听型检测词

检测词会监听普通聊天消息，匹配后自动回复。

```text
/添加检测词 [-r] <检测词> <回复内容>
/编辑检测词 [-r] <序号> <新检测词>
/删除检测词 <序号或内容>
/查看检测词列表
/查看检测词 <序号或内容>
```

`-r` 表示使用正则表达式。

### 回复条目

普通规则可以保存多条随机回复：

```text
/添加关键词回复 <规则序号或内容> <回复内容>
/编辑关键词回复 <规则序号或内容> [回复序号] <新内容>
/删除关键词回复 <规则序号或内容> [回复序号]

/添加检测词回复 <规则序号或内容> <回复内容>
/编辑检测词回复 <规则序号或内容> [回复序号] <新内容>
/删除检测词回复 <规则序号或内容> [回复序号]
```

会话式 `/添加` 创建的规则则会把多条内容视为一个有序回复序列。

## 群聊启用范围

以下命令中的“关键词”也可以替换为“检测词”：

```text
/启用关键词 <序号或内容>
/启用关键词 <序号或内容> <群号>
/启用关键词 <序号或内容> 全局

/禁用关键词 <序号或内容>
/禁用关键词 <序号或内容> <群号>
/禁用关键词 <序号或内容> 全局
```

## 回复内容

支持：

- 文字
- 图片
- At
- QQ 表情
- 语音
- 视频
- 引用消息导入
- 合并转发记录
- 多条随机回复
- 本维护版新增的多条顺序回复

引用消息导入语音、视频和聊天记录依赖 `aiocqhttp` 平台能力。

## 文本变量

回复文本可以使用：

| 变量 | 内容 |
| --- | --- |
| `{user_id}` | 触发者 ID |
| `{user_name}` | 触发者昵称 |
| `{group_id}` | 当前群号 |
| `{self_id}` | Bot ID |
| `{platform}` | 平台名称 |
| `{message}` | 原始消息文本 |
| `{date}` | 当前日期 |
| `{time}` | 当前时间 |
| `{datetime}` | 当前日期和时间 |

倒计时示例：

```text
距离活动开始还有 {countdown:2026-12-31 20:00}
```

## 主要配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `whitelist` | `[]` | 允许管理规则的非管理员用户 ID |
| `notify_permission_denied` | `true` | 无权限时是否提示 |
| `quote_reply` | `false` | 回复时是否引用原消息 |
| `qq_forward_all_replies` | `false` | 普通多回复规则是否合并转发 |
| `case_sensitive` | `false` | 是否区分大小写 |
| `cooldown` | `0` | 检测词触发冷却秒数 |
| `enable_text_template` | `true` | 是否启用文本变量替换 |

管理指令默认仅限 AstrBot 管理员和 `whitelist` 用户使用。
